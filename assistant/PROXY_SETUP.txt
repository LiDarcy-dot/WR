Прокси Telegram через VPS (Amnezia / NL)
========================================

Цель: боты ходят в Telegram через Нидерланды, а браузер
(госуслуги / банки / ЖКХ) — напрямую из РФ, без VPN на весь ПК.

С v1.015 ассистент сам пишет TELEGRAM_PROXY в .env:
  - при START_BOT.bat
  - при UPDATE.cmd / force_update
  - при каждом запуске main.py (из proxy.default)

Тебе НЕ нужно открывать блокнот и вставлять строку вручную.
Достаточно UPDATE.cmd (или перезапуск START_BOT после обновления).
Amnezia full-tunnel на Windows лучше выключить.

1) На VPS (уже сделано): microsocks :1080, юзер tgproxy.
   Скрипт: scripts/setup_tg_socks_vps.sh

2) Файл proxy.default в папке Assistant — URL SOCKS.
   Менять прокси = править proxy.default, потом START_BOT.

3) Второй бот — тот же URL из proxy.default / .env TELEGRAM_PROXY
   (см. CURSOR_PROMPT_SECOND_BOT_PROXY.txt).

4) В логе должно быть:
   Telegram API via proxy: socks5h://tgproxy:***@IP:1080
   Proxy probe api.telegram.org -> HTTP 302

5) Проверка split:
   - бот отвечает в Telegram
   - в Chrome 2ip.ru = НЕ голландский IP
   - госуслуги открываются

Браузер ассистента (позже) всегда direct — прокси только для Telegram API.
